# Dhiraj Kumar — Software Engineer Portfolio

A modern, high-performance portfolio website engineered for **Full-Stack Software Engineering & IoT Development**. Features a glassmorphic aesthetic, interactive developer terminal, real-time Firebase CMS, responsive navigation, and performance-optimized animations.

🔗 **GitHub Repository:** [https://github.com/dhirajkumar-09/My-Portfolio](https://github.com/dhirajkumar-09/My-Portfolio)

---

## ✨ Key Features & UX Enhancements

- 🖥️ **Interactive Engineering Terminal**: Simulates real-time system diagnostics, build pipelines, and telemetry with replay and copy functionality.
- 🎨 **Glassmorphism & Ambient Aesthetic**: Atmospheric radial glows, film-grain texture, and spotlight 3D hover cards with GPU acceleration.
- 📱 **Full Mobile Responsiveness**: Mobile navigation drawer with fluid animations, auto-closing on navigation or screen resize.
- ⚡ **Optimized Intro Screen**: Snappy greeting sequencer with an immediate "Skip Intro" option and session memory.
- 🗂️ **Categorized Project Filtering**: Interactive category pills (`All`, `Full-Stack`, `IoT & Systems`, `Cloud & DevOps`) with live demo and GitHub source links.
- 🧩 **Toolkit Bento Matrix**: Categorized technical stacks (Frontend, Backend & APIs, Databases & Cloud, IoT & Hardware, CS Foundations).
- 📜 **Activity Roadmap**: Connected vertical milestone timeline highlighting key architectural deployments and certifications.
- 🔒 **Live Admin CMS**: Real-time Firebase Firestore synchronization with Google OAuth authentication, inline content editing, and image compression.
- 📬 **Interactive Contact Portal**: Direct message submission with Firebase storage, one-click copy email with live feedback tooltip, and social badges.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dhirajkumar-09/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
